## Обзор  
  
`$APP->log` — фасад системы логирования фреймворка Quark. Реализован на базе  
библиотеки `QyberTech\Logger`, совместим с PHP 7.0+, не требует внешних зависимостей.  
  
Поддерживает:  
- 8 уровней логирования (PSR-3)  
- Именованные каналы с раздельными директориями  
- Автоматическую ротацию файлов по дате  
- Контекстные данные в формате JSON  
- Переопределение реализации через пользовательскую модель

| Файл | Назначение |  
|---|---|  
| `engine/facades/log.php` | Фасад `$APP->log` |  
| `engine/facades/log.ini` | Конфигурация |  
| `engine/vendor/QyberTech/Logger/Logger.php` | Библиотека логгера |

## Конфигурация  
  
Файл: `engine/facades/log.ini`  
  
```ini  
; Директория для хранения логов  
dir     = app/logs  
  
; Количество файлов на канал (старые удаляются автоматически)  
rotate  = 30  
  
; Канал по умолчанию (используется при вызове без channel())  
default = app  
  

```  
  
### Параметры  
  
| Параметр | Тип | По умолчанию | Описание |  
|---|---|---|---|  
| `dir` | string | `app/log` | Корневая директория логов |  
| `rotate` | int | `30` | Максимальное количество файлов на канал |  
| `default` | string | `app` | Имя канала по умолчанию |  
| `[channel.X] level` | string | глобальный | Настройки для канала X |  
  
---  
  
## Уровни логирования  
  
Уровни упорядочены от низшего к высшему:  
  
| Уровень | Метод | Описание |  
|---|---|---|  
| DEBUG | `debug()` | Детальная отладочная информация |  
| INFO | `info()` | Интересные события (вход пользователя, SQL-запросы) |  
| NOTICE | `notice()` | Нормальные, но значимые события |  
| WARNING | `warning()` | Нежелательные события, не являющиеся ошибками |  
| ERROR | `error()` | Ошибки выполнения, не требующие немедленного вмешательства |  
| CRITICAL | `critical()` | Критические условия (недоступен компонент) |  
| ALERT | `alert()` | Требуется немедленное действие |  
| EMERGENCY | `emergency()` | Система неработоспособна |  
  
Если для канала задан минимальный уровень в конфиге, сообщения ниже этого уровня  
не записываются. Например, при `level = warning` вызовы `debug()`, `info()`,  
`notice()` будут проигнорированы.  
  
---  
  
## Базовое использование  
  
```php  
// Запись в канал по умолчанию (из конфига, обычно 'app')  
$APP->log->debug('Начало обработки запроса');  
$APP->log->info('Пользователь вошёл в систему');  
$APP->log->notice('Использован устаревший метод API');  
$APP->log->warning('Медленный запрос к базе данных');  
$APP->log->error('Не удалось отправить email');  
$APP->log->critical('Компонент оплаты недоступен');  
$APP->log->alert('Дисковое пространство заканчивается');  
$APP->log->emergency('База данных недоступна');  
```

## Каналы  
  
Каналы позволяют разделить логи по компонентам приложения. Каждый канал  
хранится в отдельной поддиректории.  
  
```php  
// Логи аккаунтов → app/log/account/YYYY-MM-DD.log  
$APP->log->channel('account')->info('Пользователь зарегистрирован');  
$APP->log->channel('account')->warning('Неверный пароль', ['login' => 'ivan']);  
  
// Логи платежей → app/log/payment/YYYY-MM-DD.log  
$APP->log->channel('payment')->error('Ошибка списания', ['order_id' => 42]);  
  
// Логи базы данных → app/log/db/YYYY-MM-DD.log  
$APP->log->channel('db')->debug('Query executed', ['sql' => $query]);  
```  
  
`channel()` возвращает новый экземпляр логгера — оригинальный объект не изменяется.  
  
### Допустимые символы в имени канала  
  
Разрешены: латинские буквы, цифры, `-`, `_`, `.`  
  
Недопустимые символы автоматически заменяются на `_`:  
  
```php  
$APP->log->channel('my channel')->info('msg');  
// → канал 'my_channel'  
```

## Контекст  
  
Второй аргумент — массив с дополнительными данными. Записывается в лог как JSON.  
  
```php  
$APP->log->error('Ошибка авторизации', [  
    'login' => $login,  
    'ip'    => $_SERVER['REMOTE_ADDR'],  
]);  
  
$APP->log->warning('Медленный запрос', [  
    'duration_ms' => 1540,  
    'sql'         => $query,  
]);  
  
// Исключения  
try {  
    // ...  
} catch (Exception $e) {  
    $APP->log->error($e->getMessage(), [  
        'file' => $e->getFile(),  
        'line' => $e->getLine(),  
    ]);  
}  
```  
  
---  
  
## Произвольный уровень  
  
Метод `log()` принимает уровень строкой:  
  
```php  
$APP->log->log('warning', 'Сообщение с произвольным уровнем');  
$APP->log->log('debug',   'Отладка', ['key' => 'value']);  
  
// Уровень приводится к верхнему регистру автоматически  
$APP->log->log('ERROR', 'Ошибка');  
```  
  
---  
  
## Ротация файлов  
  
Ротация выполняется автоматически при каждой записи. Параметр `rotate` в конфиге  
задаёт максимальное количество файлов в директории канала. Старые файлы удаляются.  
  
```ini  
rotate = 30   ; хранить логи за последние 30 дней  
rotate = 0    ; не удалять файлы (хранить бессрочно)  
```

```  
│   ├── 2026-05-14.log  
│   └── ...  
└── payment/  
    ├── 2026-05-14.log  
    └── ...  
```

## Формат строки лога  
  
```
[2026-05-14 15:42:01] [account] WARNING: Неверный пароль {"login":"ivan","ip":"1.2.3.4"}  
```  
  
| Поле | Описание |  
|---|---|  
| `[2026-05-14 15:42:01]` | Дата и время записи |  
| `[account]` | Имя канала |  
| `WARNING` | Уровень |  
| `Неверный пароль` | Сообщение |  
| `{"login":"ivan",...}` | Контекст (если передан) |

## Переопределение логгера  
  
Фасад можно заменить собственной реализацией через пользовательскую модель.  
Создайте файл `app/models/log.php`, возвращающий объект, реализующий `QLoggerInterface`:  
  
```php  
<?php  
// app/models/log.php  
  
// Пример: использование стороннего PSR-3 совместимого логгера  
$logger = new MyCustomLogger();  
return $logger;  
```  
  
Фреймворк автоматически подключит модель вместо стандартного фасада.

## Интерфейс QLoggerInterface  
  
Все реализации логгера должны соответствовать интерфейсу `QLoggerInterface`,  
объявленному в `engine/facades/log.php`:  
  
```php  
interface QLoggerInterface  
{  
    public function emergency($message, array $context = []);  
    public function alert($message, array $context = []);  
    public function critical($message, array $context = []);  
    public function error($message, array $context = []);  
    public function warning($message, array $context = []);  
    public function notice($message, array $context = []);  
    public function info($message, array $context = []);  
    public function debug($message, array $context = []);  
    public function log($level, $message, array $context = []);  
    public function channel($name);  
}  
```  
  
Интерфейс совместим с PSR-3 (без строгой типизации для поддержки PHP 7.0+).
