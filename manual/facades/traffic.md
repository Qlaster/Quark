## Обзор

`$APP->traffic` — замер входящего трафика: фасад пишет каждое обращение
в файловый лог (`app/logs/traffic/YYYY-MM-DD.log`) и умеет читать эти
логи обратно со статистикой.

Три задачи:

- **запись** — `push()` ставит обращение в очередь, реальная запись —
  в конце запроса (деструктор), с готовым кодом ответа и таймингом
- **чтение** — `shear()` + `next()` — срез логов по диапазону дат
- **анализ** — `statistics()` — агрегаты по срезу (хиты, уникальные,
  URI, браузеры, ОС, типы устройств)

Данные — сырые файлы, строка = одно обращение, поля разделены
`delimiter`. Индексов нет — срез идёт именами файлов-дат.

## Конфигурация

`engine/facades/traffic.ini`:

```ini
#Вкл/выкл запись
enable = 1
#Директория логов; %TEMP% — временная директория системы
folder = "app/logs/traffic"
#Разделитель полей в строке лога (по умолчанию — двойной таб)
delimiter = "		"
#Имя куки-маркера посетителя (ставится на сутки, отличает уникальных)
marker = "qmark"
#Имя куки-флага «уже был сегодня»
unique = 'quid'
#Маска создания директорий логов
umask = 0755
#Буфер чтения строки лога (байт)
bufsize = 65568

#Строка-закраска значений, скрытых цензурой
ink = ▐░░░▌

#Что вложить в запись (глобал целиком или точечный лист)
[attach]
_SESSION.qlogin = 1

#Цензура: пути к значениям, которые закрашиваются
[censor]
_GET.token            = 1
_SESSION.qpassword    = 1
```

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `enable` | `1` | Запись в лог; `0`/`false` — фасад молчит |
| `folder` | `app/logs/traffic` | Каталог логов; `%TEMP%` — tmp ОС |
| `delimiter` | `"\t\t"` | Разделитель полей записи |
| `marker` | `qmark` | Кука-идентификатор посетителя (userid) |
| `unique` | `quid` | Кука-флаг «не уникален сегодня» |
| `umask` | `0755` | Права создаваемых каталогов |
| `bufsize` | `65568` | Макс. длина строки при чтении |
| `ink` | `▒▒▒▒▒` | Чем закрашиваются значения (см. [цензуру](#цензура-censor-и-ink)) |

## Запись обращений

```php
$APP->traffic->push();                  // записать обращение
$APP->traffic->push('доп. инфо');       // + произвольная строка
$APP->traffic->push(['a'=>1]);          // массивы — в json автоматом
```

`push()` ставит запись в очередь — реальный сброс в файл происходит
в `__destruct`, когда ответ уже отдан и известны `code`, `runtime`,
`mempeak`. За один запрос — одна строка лога.

```php
$APP->traffic->get_info();              // полный слепок данных обращения
```

`get_info()` кешируется внутри запроса (`static`) — повторные вызовы
бесплатны. Поля:

| Поле | Источник |
|---|---|
| `time` | `REQUEST_TIME_FLOAT` |
| `code` | `http_response_code()` на момент записи |
| `runtime` | секунды исполнения |
| `mempeak` | пик памяти, кб |
| `ip` | `client_ip()` |
| `uri` | `REQUEST_URI` (после `mask()`) |
| `type`, `osname`, `browsername`, `browserversion` | фасад `useragent` |
| `page` | маршрут без query (`url->page()`) |
| `unique` | новый посетитель за сутки |
| `userid` | маркер-кука посетителя |
| `info` | аргумент `push()` |
| `dump` | вложенные данные (`[attach]`, json) |

## Формат записи лога

Строка = поля через `delimiter`, по позициям:

```
time  code  runtime  mempeak  ip  uri  type  osname
browsername  browserversion  page  unique  userid  info  dump
```

Чтение — `string_log_parse($line)` разбирает строку обратно в массив.

---

## Чтение логов: shear и next

```php
//Срез: все логи в диапазоне дат (имена файлов Y-m-d.log)
$files = $APP->traffic->shear('2026-01-01', '2026-03-01');

//Дополнительно — фильтр строк по ключевым словам
$APP->traffic->shear('01.03.2026', '14.03.2026', ['admin', 'edit']);

//Построчная итерация по срезу
while (($line = $APP->traffic->next()) !== null)
{
    $r = $APP->traffic->string_log_parse($line);
    // $r['uri'], $r['ip'], ...
}

//next(true) — строка без обёртки (для download-выгрузки)
```

`shear` возвращает список файлов и запоминает окно; `next()` читает
файлы этого окна последовательно.

## Статистика: statistics

```php
$APP->traffic->shear('2026-11-01', '2026-11-14');
$st = $APP->traffic->statistics();        // по дням (default)
$st = $APP->traffic->statistics(false);   // суммарно за период
```

Выход — массив по датам (либо плоский при `false`):

```php
[
  'page'   => 1240,                      // всего хитов
  'unique' => 310,                       // уникальных посетителей
  'osname' => ['Windows' => 500, ...],
  'browsername' => ['Chrome' => 700, ...],
  'type'   => ['PC' => 900, 'Phone' => 340],
  'uri'    => ['/page' => 42, '/catalog' => 31, ...],
]
```

Типовой виджет — статистика дня:

```php
$APP->traffic->shear($date, $date);
$day = $APP->traffic->statistics();
```

## Маркировка посетителей

```php
$APP->traffic->mark_user();   // userid: кука на сутки для различения посетителей
$APP->traffic->is_marked();   // уже маркирован?
$APP->traffic->is_unique();   // первый заход за сутки?
$APP->traffic->client_ip();   // ip клиента
```

`mark_user()` ставит куку `marker` (сутки) — userid в логе позволяет
отличать посетителей друг от друга без привязки к логину.

## Вложение данных: attach

`[attach]` — какие данные прикрепить к записи (`dump`-поле, json):

```ini
[attach]
_SESSION          = 1    ; глобал целиком
_SESSION.qlogin   = 1    ; только $_SESSION['qlogin']
_SESSION.user.id  = 1    ; вложенность — точками, любой глубины
_GET              = 0    ; выключено
```

- Глобал целиком: `_SESSION = 1` → в лог уходит весь массив (и тогда
  обязательна цензура — см. ниже)
- Точечный лист: `_SESSION.qlogin` → только одно значение —
  лучший способ «пометить залогиненного» без слива сессии
- Отсутствующие ключи молча пропускаются

## Цензура: censor и ink

Чувствительные значения нельзя писать в лог — `[censor]` задаёт пути,
которые закрашиваются строкой `ink` **на обоих фронтах**:

```ini
ink = ▐░░░▌

[censor]
_GET.token              = 1    ; ?token=x → ?token=▐░░░▌  (и в uri!)
_POST.password          = 1
_SESSION.qpassword      = 1    ; внутри attach-дампа
_SESSION.user.secret    = 1    ; вложенность — точками
```

- `_GET` закрывает `uri` в записи (и `token=x`, и `token[]=x`,
  и `user[token]=x`, и encoded `token%5B%5D=x`)
- Прочие глобалы — внутри `[attach]`-дампа
- Пустой `[censor]` — ничего не закрашивается (нулевой оверхед)

Важно: цензура — защита в глубину, но **лучшая стратегия — не писать
вообще**. Если сессия целиком не нужна, берите точечный лист attach
вместо `_SESSION = 1`.

## Маскировка uri: mask

```php
$APP->traffic->mask('/a?x=1&token=abc');
//  /a?x=1&token=▐░░░▌
```

Публичный метод — один скомпилированный `preg_replace` с альтернацией
ключей из `[censor] _GET` (~1 мкс). Покрывает:

```
token=x          → token=▐░░░▌
token[]=x        → token[]=▐░░░▌
user[token]=x    → user[token]=▐░░░▌   (ключ — скобочный сегмент)
token%5B%5D=x    → token%5B%5D=▐░░░▌   (encoded-скобки)
a=1;token=x      → ; как разделитель тоже учитывается
```

Границы имён соблюдаются: `xtoken`, `tokenize`, `my.token` —
не трогаются. Регистрозависимо, как и сам GET.

## Вспомогательные методы

```php
$APP->traffic->runtime();        // время исполнения (сек)
$APP->traffic->mempeak();        // пик памяти (кб)
$APP->traffic->date();           // текущая дата лога (Y-m-d)
$APP->traffic->statistics();     // см. выше
$APP->traffic->string_log_parse($line);  // строка → массив
```
